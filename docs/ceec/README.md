# CEEC Homepage Starter Site

This package converts the approved homepage concept into a responsive static website.

## Files
- `index.html` — homepage
- `styles.css` — full responsive styling
- `script.js` — mobile navigation and copyright year
- `orderform.html` — starter made-to-order request form
- `review.html` — starter review form
- `assets/` — placeholder images and the original visual reference

## Before publishing
1. Replace placeholder SVG files with Carmen's real product photos.
2. Replace both `REPLACE_WITH_FORM_ID` values with the correct Formspree form IDs.
3. Replace placeholder links (`href="#"`) with live shop, product, social, and policy URLs.
4. Replace sample reviews with approved customer reviews.
5. Generate a real QR code that points directly to `review.html`.
6. Confirm the business location wording in the footer.
7. Upload all files to the GitHub Pages repository.

## Notes
- The homepage is responsive for desktop, tablet, and mobile.
- The current shop links are structural placeholders.
- The QR block is decorative until replaced with a real QR image.
- Google Fonts are loaded remotely. They can be replaced with local/system fonts if desired.
